<p class="pm-kind"><b>Part opener</b> · for people who already run Pulse Mesh</p>

A guide does not teach. It names the task, states what you need, and gives the steps in order, with the result you should see after each one. Background belongs in the [Concepts](../explanation/README.md) part and exact facts in the [Reference](../reference/README.md) part; a guide links to both instead of repeating them.

- [Tune the UDP transport](tune-udp.md): backpressure, retransmission and parity, and their counters.
- [Write a language binding](write-a-binding.md): the vectors, chapter 3, and how the tree proves conformance.
- [Run the smoke bench and read the result](run-the-benches.md): the one command, the count to check first, and what each field means.

The guides for running the daemon (installing `pms`, running the daemon as a service, capturing envelopes, the MCP server, shared memory, troubleshooting, adding a stage to a ring) are in [the daemon's book](/docs/daemon/guides/README.html).
